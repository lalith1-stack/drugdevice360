# Drug Device 360

Website for **Drug Device 360 (DD360)**, a consultancy for drug-device combination products.

Live site: https://lalith1-stack.github.io/drugdevice360/

## What's here

| Path | What it is |
| --- | --- |
| `index.html` | The whole website: one page, with all styles and scripts inside it |
| `assets/` | Logo files (SVG and PNG), app icons, favicon and the social share image |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

## Updating the site

Edit `index.html` (on github.com: open the file, click the pencil icon, then **Commit changes**).
The live site updates about a minute after each commit.

## Logo usage

- `assets/dd360-logo-horizontal.svg`: main logo for light backgrounds
- `assets/dd360-logo-horizontal-white.svg`: main logo for dark backgrounds
- `assets/dd360-logo-stacked*.svg`: square-ish spaces (profile banners, documents)
- `assets/dd360-mark.svg`, `assets/icon-512.png`: icon only (LinkedIn avatar, favicon)

Brand colours: Ink `#0B1626` · Cobalt `#2B59FF` · Coral `#FF5A36`
Fonts: Hanken Grotesk (headings and text), IBM Plex Mono (labels)
